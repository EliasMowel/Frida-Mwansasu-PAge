# Frida Mwansasu Portfolio

A responsive personal portfolio built with Vite.

## Run locally

```bash
npm install
npm run dev
```

## Build for publishing

```bash
npm run build
```

Upload the generated `dist` folder to a static host such as Netlify, Vercel, GitHub Pages, or Cloudflare Pages. After the final domain is connected, add that URL to Google Search Console and submit a sitemap for indexing.

## Before publishing

- Replace the portrait artwork in `src/style.css` with Frida's approved image.
- Replace the placeholder project names and descriptions with the client's real work.
- Update the email address and social profile links in `src/main.js`.
- Update the page title and description in `index.html` if the client's final professional title changes.
